# Appendix A — Instrument Frequency Chart

A consolidated quick-reference for EQ (Chapter 9) and effects (Chapters 10–11).
**Every value is a starting point** — sweep around it and judge in the full mix.

## The spectrum at a glance

| Zone | Range | Character | Typical move |
|------|-------|-----------|--------------|
| Sub-bass | 20–60 Hz | Felt, not heard; rumble | HPF most non-bass tracks |
| Bass | 60–250 Hz | Weight, power, fundamentals | Power *and* mud both live here |
| Low-mids | 250–500 Hz | Warmth / **mud / boxiness** | Most common cut zone |
| Mids | 500 Hz–2 kHz | Body, "honk," attack | Cut box ~400–600 Hz; nasal ~1 kHz |
| High-mids | 2–6 kHz | Presence, clarity, bite **& harshness** | Boost to cut through; cut if harsh |
| Highs | 6–12 kHz | Brilliance, detail, sibilance | Sibilance ~5–9 kHz (de-ess) |
| Air | 12–20 kHz | Openness, sheen | Gentle high shelf for sparkle |

## Per-instrument cheat sheet

> HPF = high-pass filter (low-cut). All values approximate.

### Electric guitar
| Goal | Frequency |
|------|-----------|
| HPF (remove low rumble) | 80–100 Hz |
| Body / "meat" (preserve) | 200 Hz–1 kHz |
| Mud / congestion (cut) | 300–500 Hz |
| Presence / bite (boost) | 2.5–5 kHz |
| Fizz (high-cut/shelf if harsh) | above 6–8 kHz |

### Acoustic guitar
| Goal | Frequency |
|------|-----------|
| HPF | 70–100 Hz |
| Boom (cut) | 150–300 Hz |
| Boxiness / honk (cut) | 500 Hz–1 kHz |
| Pick attack / clarity (boost) | 2–5 kHz |
| Sparkle / air (boost) | 8–12 kHz |

### Bass guitar
| Goal | Frequency |
|------|-----------|
| HPF (sub-rumble only) | 30–40 Hz |
| Bottom / sub | 40–80 Hz |
| Fundamentals / power ("the magic") | 80–200 Hz |
| Boom (cut if flubby) | 180–250 Hz |
| Definition / growl (boost — translates on small speakers) | 700 Hz–2.5 kHz |
| String/pick clack | 2.5–5 kHz |

### Keyboard / piano / synth
| Goal | Frequency |
|------|-----------|
| HPF (bright pads/organs/leads) | 60–120 Hz |
| Warmth vs. mud (focus zone) | 50–250 Hz |
| Mud / boxiness (cut) | 200–500 Hz |
| Presence / clarity (boost) | 3–6 kHz |
| Air / polish (high shelf) | 10–14 kHz |

### Vocals
| Goal | Frequency |
|------|-----------|
| HPF (min; higher for thin voices) | 80–120 Hz |
| Warmth / body | 100–250 Hz |
| Mud / chestiness (cut) | 200–400 Hz |
| Boxiness / honk (cut) | 500 Hz–1 kHz |
| Presence / intelligibility (boost) | 3–6 kHz (clarity often 4–9 kHz) |
| Sibilance (de-ess, don't EQ) | 5–9 kHz |
| Air / sheen (high shelf) | 10–16 kHz |

## Effect quick-reference

| Effect | Use it for | Key control |
|--------|-----------|-------------|
| Compression | Even out dynamics, add punch/glue | Threshold, ratio, attack, release |
| Limiter | Cap peaks, master loudness | Ceiling |
| Gate | Silence noise/bleed (high-gain gtr) | Threshold |
| De-esser | Tame "s"/"sh" on vocals | Frequency (~5–9 kHz) |
| Reverb | Depth, space, ambience | Type, decay, pre-delay (EQ the return!) |
| Delay | Echo, width, clarity-friendly space | Time (tempo-sync), feedback |
| Chorus | Width/shimmer (clean gtr, Rhodes, pads, BVs) | Depth, rate |
| Saturation | Warmth, density, small-speaker translation | Drive |

## Reverb/delay rules of thumb
- Put reverb/delay on **sends**, not inserts (share the space; EQ the return).
- **High-pass** reverb returns ~200–300 Hz; roll off highs to sit it back.
- **Pre-delay** ~20–60 ms keeps the dry source in front.
- **Haas** (<40 ms L/R) = width without an audible echo.
- **Slapback** ~80–120 ms thickens vocals/rockabilly guitar.
